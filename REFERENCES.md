# References and Further Reading

Many original URLs (developer.symbian.org, forum.nokia.com, developer.symbian.com) are offline. Search the [Internet Archive Wayback Machine](https://web.archive.org/) for the original addresses. Check every link before relying on it.

## Books
* *Symbian C++. Программирование для мобильных телефонов*. Williams Publishing, 2010 (Russian). Primary source for this documentation. A community copy of the text is published at [trufanov-nok/SymbianBook_ru](https://github.com/trufanov-nok/SymbianBook_ru).
* J. Stichbury, *Symbian OS Explained: Effective C++ Programming for Smartphones*. Wiley, 2004. ISBN 0470021306. The classic on idioms; includes the *Hercules* client–server example.
* J. Stichbury, M. Jacobs, *The Accredited Symbian Developer Primer: Fundamentals of Symbian OS*. Wiley, 2006. ISBN 9780470058275.
* R. Harrison, M. Shackman, *Symbian OS C++ for Mobile Phones, Vol. 3*. Wiley, 2007. ISBN 0470066415.
* C. Heath, *Symbian OS Platform Security*. Symbian Press, 2006. ISBN 0470018828.
* J. Sales, *Symbian OS Internals: Real-time Kernel Programming*. Symbian Press, 2005. ISBN 0470025247.
* B. Morris, *The Symbian OS Architecture Sourcebook*. Wiley, 2007. ISBN 9780470018460.
* I. Campbell, *Symbian OS Communications Programming*, 2nd ed. Wiley, 2007. ISBN 9780470512289.
* *Porting to the Symbian Platform: Open Mobile Development in C/C++*. Wiley, 2009.
* *Data Sharing and Persistence with Symbian C++*. Symbian Press, 2009.

## Platform history (2010–2014)
* Nokia ended Symbian/MeeGo Store submissions on 1 January 2014, and Symbian Signed closed at the start of 2014: [TechSpot](https://www.techspot.com/news/55188-nokia-officially-shuts-the-doors-on-symbian-and-meego-app-support.html), [The Register](https://www.theregister.com/2013/10/09/nokia_shuts_symbian_meego_stores_early), [All About Symbian: Certified signing to stop after 13 December](https://allaboutsymbian.com/flow/item/18633_Official_Certified_application.php).
* [Symbian Shutters Its Sites (Light Reading)](https://www.lightreading.com/business-management/symbian-shutters-its-sites). Symbian declared closed source again in 2011: [RCR Wireless](https://www.rcrwireless.com/20110408/wireless/symbian-officially-declared-closed-source).

## Tools and communities today
* [awesome-symbian](https://github.com/hstsethi/awesome-symbian): curated list of Symbian resources.
* [EKA2L1](https://github.com/EKA2L1/EKA2L1): Symbian/N-Gage emulator.
* [GCC4Symbian](https://github.com/fedor4ever/GCC4Symbian) / [gcce4symbian](https://sourceforge.net/projects/gcce4symbian/): modern GCC builds for Symbian.
* [Qt wiki: Support for Symbian](https://wiki.qt.io/Support_for_Symbian).
* [Carbide.c++ (Wikipedia)](https://en.wikipedia.org/wiki/Carbide.c%2B%2B).
* [Mika Raento's Symbian programming pages](https://mikie.iki.fi/symbian/resources.html): classic tips and pitfalls.
* Communities: [r/Symbian](https://reddit.com/r/Symbian), the EKA2L1 Discord, Symbian-focused Telegram groups.
